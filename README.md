# Dietory Downloads

Official Windows installer downloads for Dietory Lifetime. This repository contains **only distribution files and release notes**; the application's source code is not published here.

## Download

Use the [latest release](https://github.com/rezawizard/Dietory-Downloads/releases/latest) to download the Windows installer. No GitHub account is required.

## Installation

Download `Dietory-5.5.0-Lifetime-Setup.exe`, run it on Windows and follow the installer. This is the offline lifetime edition; no monthly subscription is required.
